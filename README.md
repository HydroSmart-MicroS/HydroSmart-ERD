# HydroSmart ERD

Visor del modelo de datos de HydroSmart. Reúne un mapa general, 13 láminas por tema y el ERD completo con zoom. Incluye fuentes PlantUML, diagramas SVG y el catálogo de metadatos del esquema.

Abre index.html en un navegador para explorar las láminas. El botón **Ver ERD completo** permite ampliar el diagrama y arrastrarlo para recorrerlo.

## Publicación en GitHub Pages

En **Settings → Pages**, selecciona **Deploy from a branch**, la rama **main** y la carpeta **/(root)**. Guarda los cambios. [Guía de GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

El catálogo refleja el esquema de MAIN verificado el 8 de noviembre de 2026. Las conexiones FK representan restricciones físicas y las REF representan referencias lógicas entre entidades.
